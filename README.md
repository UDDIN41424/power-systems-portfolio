# Power Systems Portfolio

Studies on European benchmark grids, written in Python (pandapower, pandas, matplotlib). Each project compares a new scenario against the standard way of operating the grid. The data is realistic, not real, and each project's README states its limits.

Author: Muhammad Shahab Uddin, electrical engineer (BSc UET Peshawar), MSc Artificial Intelligence at JKU Linz, based in Linz, Austria.

## Projects

| # | Project | Topic | Status |
|---|---|---|---|
| 01 | [Short-circuit levels and overcurrent protection in a weakening MV grid](01-short-circuit-protection) | IEC 60909, CIGRE MV benchmark, inverter-based DER | Done |
| 02 | Harmonics and EN 50160 compliance | Power quality | Planned |
| 03 | Load forecasting with APG / ENTSO-E data | Time series versus baselines | Planned |
| 04 | Transformer fault classification from gas analysis | IEC 60599 versus machine learning | Planned |

## Tools
Python, pandapower, pandas, NumPy, matplotlib, Jupyter.
